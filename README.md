# مُجهّز أسئلة الامتحان — نسخة مجانية بالكامل (بدون بطاقة، بدون دفع)

هاي نسخة معدّلة تشتغل بدون أي تكلفة:
- **الاستضافة**: Cloudflare Pages — مجاني للأبد، بدون بطاقة ائتمان.
- **الذكاء الاصطناعي**: Gemini API من Google (Google AI Studio) — مجاني بحدود
  استخدام يومية سخية (كافية جداً لتحليل صور امتحانات شخصياً)، بدون بطاقة.

⚠️ ملاحظة صغيرة: صار التحليل يستخدم موديل Gemini بدل Claude. الجودة قريبة
جداً وبتفهم العربي والفرنسي منيح، بس جرّبها بصورة حقيقية وراجع النتيجة قبل
ما تعتمد عليها، مثل ما كانت الصفحة أصلاً بتنصح.

## الخطوة 1: مفتاح Gemini مجاني
1. روح لـ https://aistudio.google.com/apikey
2. سجّل دخول بحساب Google عادي (ما في بطاقة ولا اشتراك مطلوب)
3. اضغط "Create API key" وانسخ المفتاح

## الخطوة 2: ارفع المجلد على GitHub
ارفع هالمجلد (`exam-tool-free`) كـ repo جديد (خاص أو عام، مش مهم).

## الخطوة 3: انشره على Cloudflare Pages
1. سجّل حساب مجاني على https://dash.cloudflare.com (بدون بطاقة)
2. من القائمة: Workers & Pages → Create → Pages → Connect to Git
3. اختر الـ repo
4. إعدادات البناء:
   - Framework preset: **None**
   - Build command: (اتركه فاضي)
   - Build output directory: `/`
5. اضغط Save and Deploy

## الخطوة 4: ضيف مفتاح Gemini كمتغيّر بيئة
1. من صفحة المشروع على Cloudflare: Settings → Environment variables
2. ضيف متغيّر: `GEMINI_API_KEY` = المفتاح يلي نسخته بالخطوة 1
3. (اختياري) ضيف كمان `APP_SECRET` = أي كلمة سر، لمنع استخدام غيرك للرابط
   — إذا حطيته، افتح `index.html` وحط نفس القيمة بسطر:
   `const APP_SECRET = '...';`
4. أعد النشر (Retry deployment) حتى يطبّق المتغيرات

بعدها رح ياخد مشروعك رابط دائم شكله `اسم-المشروع.pages.dev` — تفتحه من أي
متصفح وبأي وقت، بدون أي تكلفة.

## هل في طريقة أسهل وأسرع من هاي؟
إي — إذا بس بدك تستخدم الأداة بدون ما تعدّي كل هالخطوات، فيك تفتح نفس ملف
الأداة الأصلي (`مجهز_الأسئلة.html`) جوا محادثة Claude نفسها (بلّشها كـ
Artifact) وتستخدمها من هناك مباشرة — مجاني ضمن حساب Claude العادي تبعك،
بدون أي إعداد أو مفتاح API. الفرق الوحيد إنها بتشتغل بس وانت فاتح Claude،
مش كموقع مستقل.
